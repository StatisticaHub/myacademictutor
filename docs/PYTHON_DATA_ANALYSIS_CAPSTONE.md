# Python for Data Analysis — Capstone Brief

## Scenario

You are given a participant-level dataset from a fictional learning programme.
The task is to evaluate score patterns, data quality and the association between
programme group and final score while producing a reproducible analytical
package.

## Minimum data schema

| Variable | Meaning |
|---|---|
| participant_id | unique participant label |
| group | programme group A/B |
| age | age in years |
| region | participant region |
| baseline_score | score before programme |
| final_score | score after programme |
| visit_date | assessment date |
| completed | completion indicator |

## Required workflow

1. Define the unit of observation and analytical question.
2. Audit shape, types, missingness, duplicate identifiers and ranges.
3. Clean text/date/numeric columns using documented rules.
4. Derive score change and any justified analysis variables.
5. Produce descriptive summaries by group.
6. Visualise score distributions and baseline/final relationships.
7. Fit a simple model of final score using group and baseline score.
8. Perform at least one justified sensitivity analysis.
9. Export one final table and two figures.
10. Write a README and rerun the workflow from a fresh state.

## Required outputs

- `outputs/tables/data_audit.csv`
- `outputs/tables/group_summary.csv`
- `outputs/tables/model_results.csv`
- `outputs/figures/final_score_distribution.png`
- `outputs/figures/baseline_final_relationship.png`
- concise methods/results note
- reproducible notebook/script
- dependency/environment record

## Quality rubric

### Data integrity — 25%
- unit of observation correctly identified
- duplicate/key checks appropriate
- missingness visible
- range/type checks explicit
- raw data preserved

### Python/pandas workflow — 25%
- readable transformations
- appropriate NumPy/pandas use
- merge and reshape logic validated
- reusable functions where helpful
- no undocumented manual edits

### Analysis and interpretation — 25%
- summaries answer the stated question
- graphics reveal relevant structure
- model interpretation is accurate
- association is not presented as causation
- sensitivity analysis is reported transparently

### Reproducibility and communication — 25%
- clean rerun succeeds
- outputs generated by code
- README explains execution
- dependencies recorded
- tables/figures clearly labelled
- conclusions trace back to verified outputs
