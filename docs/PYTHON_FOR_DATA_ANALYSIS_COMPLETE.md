# Python for Data Analysis — Corrected Complete Course

## Course structure

### Module 1 — Python foundations for analysis
1. The data-analysis workflow in Python
2. Variables, types and collections
3. Control flow and functions
4. Writing analysis-ready Python

### Module 2 — NumPy for numerical work
5. Arrays and vectorisation
6. Indexing, masks and broadcasting
7. Numerical summaries and missing values
8. Randomness and simulation

### Module 3 — pandas foundations
9. Series and DataFrames
10. Selecting, filtering and sorting
11. Creating and transforming columns
12. Import, export and data types

### Module 4 — Cleaning and reshaping data
13. Missing data in practice
14. Strings, categories and labels
15. Duplicates, outliers and validation
16. Tidy data and reshaping

### Module 5 — Grouping and combining data
17. GroupBy and aggregation
18. Pivot tables and cross-tabulations
19. Merging and joining tables
20. Transform, apply and window operations

### Module 6 — Exploratory analysis and visualisation
21. Describing a dataset responsibly
22. Plotting with pandas and Matplotlib
23. Distributions and relationships
24. An end-to-end EDA workflow

### Module 7 — Time series and reproducible workflows
25. Dates, times and time indexes
26. Resampling and rolling summaries
27. Reusable analysis pipelines
28. Debugging, testing and performance

### Module 8 — Capstone: raw data to decision-ready analysis
29. Frame the question and audit the data
30. Build the analysis pipeline
31. Visualise, compare and explain
32. Produce a reproducible analysis report

## Formal assessment

- 8 module checkpoints × 8 questions = 64
- 32-question cumulative final assessment
- 96 formal questions total
- 70% pass threshold
- all lessons + checkpoints + final assessment required
- certificate enabled after formal completion

## Reusable learning primitives

The course uses:

```ts
type: "code-example"
type: "python-data-lab"
```

The code block supports:

```ts
code
output
note
```

so learners can see a command, its expected result and an analytical note in one
coherent unit.

The interactive framework supports the authored course lab keys:

- workflow
- numpy
- dataframe
- missing
- quality
- groupby
- merge
- eda
- eda-workflow
- time
- capstone
- capstone-report
